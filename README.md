# AI/ML Project

## About the Project

This project is developed as part of a Coursera AI/ML course. 
It focuses on applying Artificial Intelligence and Machine Learning concepts 
to solve a practical problem using Python.

## Objectives

- Understand the fundamentals of Artificial Intelligence and Machine Learning.
- Perform data preprocessing and analysis.
- Build and train a machine learning model.
- Evaluate the performance of the model.
- Apply machine learning techniques to real-world data.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook
